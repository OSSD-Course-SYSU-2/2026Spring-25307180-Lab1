 项目介绍
 
本项目是一款经典趣味猜数字小游戏，属于编程入门实战项目。系统自动随机生成1～100之间的整数作为目标数字，用户通过输入数字进行猜测，程序实时比对并给出数字偏大、数字偏小提示，引导用户不断缩小范围，直至成功猜中。整体交互简洁流畅，逻辑清晰，适合新手学习循环、分支、随机数、输入校验等基础编程思想，也可作为课程作业与GitHub练手仓库项目。

功能特性
 
1. 随机生成1–100之间的目标神秘数字，每局游戏数字不重复。
2. 实时判断用户输入，给出过大、过小、猜对文字提示。
3. 严格输入合法性校验，拦截非数字、超出范围的无效输入。
4. 自动统计本局猜测总次数，猜中后展示游戏成绩。
5. 支持循环游玩，可随时重新开始新一轮游戏。
6. 代码分层清晰，注释详尽，易阅读、易修改、易二次开发。
 
技术亮点
 
1. 运用随机数生成、条件判断、循环语句等基础核心语法。
2. 完善的异常输入处理，提升程序健壮性。
3. 模块化代码设计，功能独立，便于后续扩展难度选择、计分系统、历史记录等功能。
4. 结构规范，符合开源项目仓库文档标准，适合GitHub上传展示。
